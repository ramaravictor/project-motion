DESKRIPSI
UI hasil vibe coding lo gradien ungu, judul penuh emoji, tiga kotak fitur kembar? Klien langsung tahu itu AI polosan 💀

Obatnya: colok 21st MCP ke Antigravity IDE. AI lo nggak ngarang CSS lagi, tapi ambil komponen beneran dari registry 21st.dev (12.000+ komponen React & Tailwind: hero, card, navbar, background).

Cara colok:
1. Ambil API key gratis di 21st.dev/mcp
2. Antigravity IDE → MCP Servers → tempel config HTTP
3. Prompt UI seperti biasa, sekarang hasilnya naik kelas

Config lengkap ada di komentar yang gue pin. Ketik "UI" di komentar kalau mau gue bahas lebih dalam 👇
